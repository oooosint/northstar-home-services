# Northstar Home Services

> **Portfolio concept — not a real business or commissioned client project.** Company names, services, pricing, and appointments are for demonstration only.

A responsive home-services website concept with service sections, trust-building content, and a demo quote form.

**Live demo:** https://northstar-home-lemon.vercel.app/

## Tech stack
- Next.js 15 (App Router)
- React 19 and TypeScript
- Tailwind CSS 4 / custom CSS
- Responsive layouts and semantic HTML

## Quick start

Install Node.js 20.9+ and run:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
npm run build
npm start
```

## Features
- Responsive layouts for desktop and mobile
- Service sections and visual presentation
- Contact / booking form with browser validation
- Accessible page sections and metadata

## Demo limitation
**The contact / booking form is a demonstration only.** The site displays an on-page confirmation; it does **not** send emails, process bookings, or store customer data. Connect a secure backend and update the user-facing notices before accepting real submissions.

## Deployment
This site is deployed at https://northstar-home-lemon.vercel.app/. You can deploy your own version on Vercel by importing this repository and choosing Next.js with the default configuration. No environment variables are needed for the demo.
